# Telarsa/.github

The organisation's shared GitHub files.

- `profile/README.md` is the page shown at [github.com/Telarsa](https://github.com/Telarsa).
- `SECURITY.md` and `CODE_OF_CONDUCT.md` are the defaults every Telarsa repository inherits unless it carries its own.
- `profile/*.svg` is the mark the profile page renders, in a light and a dark variant.
