# Code of conduct

Be direct, be kind, and argue about the work rather than the person.

We welcome contributions from anyone. In our repositories and discussions that
means: no harassment, no discrimination, no personal attacks, and no publishing
of anyone's private information. Disagreement is fine and expected; contempt is
not.

If something crosses that line, write to [hello@telarsa.com](mailto:hello@telarsa.com).
Reports are read by a person, kept confidential, and acted on.
