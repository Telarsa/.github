# Security policy

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting on the repository concerned, or
write to [hello@telarsa.com](mailto:hello@telarsa.com) with "security" in the
subject. Tell us what you found, how to reproduce it, and what an attacker
could do with it. We confirm receipt, say what we think, and credit you when a
fix ships unless you would rather we did not.

The latest release of each project is the supported one; fixes go to the next
tag.
